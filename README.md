# A Aventura de Lucas & Gigi

Protótipo jogável em Next.js criado a partir das cartas e fotos fornecidas.

## O que já funciona

- abertura cinematográfica;
- mapa vivo com névoa, partículas, trilha visual e nove regiões;
- regiões bloqueadas/desbloqueadas;
- Vila Inicial com narrativa, pergunta e alternativas;
- resultado correto com XP, moeda, item e desbloqueio da Floresta;
- resultado errado com Dado do Destino animado;
- seis penalidades do D6;
- HUD, inventário e progresso;
- salvamento automático no navegador;
- efeitos sonoros sintetizados sem arquivo externo;
- adaptação para computador e celular.

## Como abrir

1. Instale o Node.js 20 ou superior.
2. Abra a pasta no terminal.
3. Execute:

```bash
npm install
npm run dev
```

4. Abra `http://localhost:3000`.
